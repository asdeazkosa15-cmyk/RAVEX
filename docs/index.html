الأسئلة الشائعة

بعض الإجابات السريعة

هل الموقع يعمل على الهاتف؟

نعم، التصميم متجاوب مع الهاتف والتابلت والكمبيوتر.

هل أستطيع إضافة ألعاب جديدة؟

نعم، الألعاب موجودة في مصفوفة JavaScript داخل الكود ويمكن إضافة ألعاب بسهولة.

أين أضع روابط MEGA؟

كل لعبة تحتوي على مكان مخصص لرابط MEGA داخل بيانات اللعبة.

هل الفيديو يفتح خارج الموقع؟

لا، الفيديو مدمج داخل صفحة RAVEX بواسطة مشغل YouTube.

هل يوجد قسم للبرمجة؟

نعم، يوجد قسم مستقل لأدوات البرمجة والتطوير.

هل أستطيع تغيير صور الألعاب؟

نعم، كل لعبة لديها رابط صورة مستقل ويمكن تغييره من بيانات اللعبة.
